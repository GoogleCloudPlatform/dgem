# Evaluation datasets

Small datasets used by the `dgem bench-*` harnesses and the regression matrix (`scripts/bench_matrix.py`).
Run them against your own deployment; results are written wherever you point `-o` / `--out-dir`.

## First-party synthetic datasets & lockfiles (`benchmarks/`, Apache-2.0)

All files under `benchmarks/` are original synthetic evaluation fixtures or SHA-256 lockfiles authored for this project under Apache-2.0:

| File | Used by | Description | Licence |
|---|---|---|---|
| `eval_dataset.jsonl` | `dgem bench` | Original synthetic support-triage, code-review, and security-incident items written for this project | Apache-2.0 |
| `calibration_suite.jsonl` | `dgem bench-calibration` | Original synthetic items written from scratch for this project (covering prompt-injection, toxicity, emotions, NLI, intents, agent-step drift, and grounding task formats) | Apache-2.0 |
| `permutation_suite.jsonl` | `dgem bench-permutation` | Original synthetic option-order items written for this project | Apache-2.0 |
| `decision_index/panel_suite.jsonl` | `dgem bench-decision-index` | Original synthetic items written from scratch for this project (task-area names are category labels only) | Apache-2.0 |
| `ecotone/tn_semiotics.jsonl`, `ecotone/tn_challenge_en.jsonl` | `templates/tn_disambiguation.json.tmpl` | Original synthetic text-normalization items written for this project | Apache-2.0 |
| `bbox_suite.jsonl`, `bbox_sweep.jsonl`, `../fixtures/bbox/`, `../fixtures/*.svg` | `dgem bench-bbox`, `dgem bench-vision` | Synthetic geometric fixtures generated by `scripts/generate_bbox_fixtures.py` / `scripts/generate_bbox_sweep.py` | Apache-2.0 |
| `jevbench/manifest.lock.json` | `dgem bench-jev --sync` | SHA-256 lockfile and commit pin for runtime download of [JevBench](https://github.com/fstandhartinger/jevbench) (contains only URLs and SHA-256 digests, no dataset items) | Apache-2.0 |
| `matrix/datasets.lock.json` | `scripts/bench_matrix.py fetch` | SHA-256 lockfile and commit pins for runtime download of the six Hugging Face datasets listed below (contains only URLs and SHA-256 digests, no dataset items) | Apache-2.0 |

## Fetched at run time (not committed)

- **JevBench public tasks** (MIT): `dgem bench-jev --sync` downloads `benchmarks/jevbench/jevbench_public.jsonl` at the pinned
  release and verifies it against `benchmarks/jevbench/manifest.lock.json`.
- **Matrix datasets**: `scripts/bench_matrix.py fetch` downloads the pinned files into `~/.cache/dgem-matrix` and
  verifies their SHA-256 (a suite also downloads what it needs on first use). The parquet ones need `pyarrow`
  (`pip install -r scripts/requirements-matrix.txt`). Each file is pinned to a Hugging Face commit in
  `benchmarks/matrix/datasets.lock.json`, which records the upstream dataset licence:

  | Dataset | Used by | Upstream Licence |
  |---|---|---|
  | [mteb/amazon_massive_intent](https://huggingface.co/datasets/mteb/amazon_massive_intent) (MASSIVE) | `massive_spot`, `massive`, `di_wide`, option order | CC BY 4.0 |
  | [facebook/xnli](https://huggingface.co/datasets/facebook/xnli) | `xnli`, option order | CC BY-NC 4.0; downloaded at run time, never redistributed |
  | [LocalLLaMA/typed-decisions](https://huggingface.co/datasets/LocalLLaMA/typed-decisions) | `typed` | Apache-2.0 |
  | [dair-ai/emotion](https://huggingface.co/datasets/dair-ai/emotion) | option order | See the dataset card (research and educational use); downloaded at run time |
  | [clinc/clinc_oos](https://huggingface.co/datasets/clinc/clinc_oos) | `di_catchall` (validation split) | CC BY 3.0 |
  | [wandb/RAGTruth-processed](https://huggingface.co/datasets/wandb/RAGTruth-processed) | `rag_dev` (train split) | See the dataset card (RAGTruth annotations are MIT; contexts come from the source datasets); downloaded at run time |

- **Real images** for `third_party/bbox_real/bbox_real.jsonl`: `scripts/fetch_bbox_real.py fetch`.

If you add a dataset, record its source and licence here. Any dataset derived from third-party material must live under `third_party/<name>/` with its `LICENSE` file; prefer a pinned fetch script over committing third-party data.
