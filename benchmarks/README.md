# Evaluation datasets

Small datasets used by the `dgem bench-*` harnesses and the regression matrix (`scripts/bench_matrix.py`).
Run them against your own deployment; results are written wherever you point `-o` / `--out-dir`.

## Fetched at run time (not committed)

- **JevBench public tasks**: `dgem bench-jev --sync` downloads `jevbench/jevbench_public.jsonl` at the pinned
  release and verifies it against `jevbench/manifest.lock.json`.
- **MASSIVE, XNLI, typed-decisions**: `scripts/bench_matrix.py fetch` downloads the pinned files into
  `~/.cache/dgem-matrix` and verifies their SHA-256.
- **Real images** for `bbox_real.jsonl`: `scripts/fetch_bbox_real.py fetch`.

If you add a dataset, record its source and licence here, and prefer a pinned fetch script over committing
third-party data.
